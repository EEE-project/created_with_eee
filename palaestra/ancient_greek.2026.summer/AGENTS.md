```

  notebook.py          # index/parent notebook
  2026_06_09/          # Занятие 1 · Алфавит и повелительное наклонение
  2026_06_12/          # Занятие 2 · Ударения и просодия
  2026_06_16/          # Занятие 3 · Глаголы и синтаксис
  2026_06_19/          # Занятие 4 · Средний залог и II склонение
```

Each lesson directory:

```
notebook.py
verbs.tsv          ← vocabulary (Word + Translation, 2-col)
nouns.tsv          ← same format (if present)
adjectives.tsv     ← same format (if present; may include nouns in the adj POS slot)
particles.tsv      ← same format (if present)
adjs.tsv           ← adjective base forms for ADV drill (lessons with adverb exercise)
*.pdf              ← handouts — linked in homework / class-materials cells
```

## Two notebook patterns

### Pattern A — word_drill × 2  (2026_06_09)

Used when the exercise tests **inflected forms generated by the EEE backend**
(e.g. imperative sg/pl from `verbs.tsv`, adverbs derived from `adjs.tsv`).

Requires `AncientGreekBackend` + `gu.load_slot_drill` to build `VERBS`, then
expands to a flat `VERB_ENTRIES` list (one entry per field) so `word_drill_form`
can handle it — gaining Prev/history navigation without a custom advance function.

### Pattern B — word_quiz + word_drill  (2026_06_16, 2026_06_19)

Used when the exercise **presents the form from the TSV as-is** — either as a
multiple-choice quiz or a write-the-word drill from `VOCAB_WORDS`.

Does NOT need a backend: `gu = GreekUtils(mo_module=mo, config=ANCIENT_GREEK)`.

## Backend setup (Pattern A only)

```python
import eee_project as eee
from ancient_greek_backend_eee import AncientGreekBackend
from eee_project import GreekUtils, ANCIENT_GREEK

ag = AncientGreekBackend(lexicons=["pratt", "ltrg", "homer", "lxx", "morphgnt"])
eee.register_backend("grc", ag)
eee.register_backend("grc", ag, backend="ancient-greek")
eee.set_chain("grc", ["ancient-greek"])

gu = GreekUtils(ag, mo, eee_module=eee, config=ANCIENT_GREEK)
```

Pattern B (no backend):
```python
from eee_project import GreekUtils, ANCIENT_GREEK
gu = GreekUtils(mo_module=mo, config=ANCIENT_GREEK)
```

## Exercise code patterns

### verb word_drill (Pattern A, e.g. imperative sg/pl)

`gu.load_slot_drill` builds `VERBS` (one dict per verb with computed form fields).
A flat expansion into `VERB_ENTRIES` (one entry per field) lets `word_drill_form`
handle navigation — including Prev — without a custom advance function.

```python
# Setup cell: load vocab, expand to flat entries
_IMP = {"VerbForm": "Fin", "Tense": "Pres", "Voice": "Act", "Mood": "Imp"}
VERBS = gu.load_slot_drill(
    gu.ensure_file("verbs.tsv", nb_dir=NB_DIR, remote_base=NB_REMOTE),
    {"verb": None,
     "sg": {**_IMP, "Person": "2", "Number": "Sing"},
     "pl": {**_IMP, "Person": "2", "Number": "Plur"}},
    pos="verb",
)
_FIELDS_V = [('verb', 'словарная форма'), ('sg', 'повел. ед. ч.'), ('pl', 'повел. мн. ч.')]
VERB_ENTRIES = [
    {"meaning": f"{v['meaning']} ({lbl})", "form": v[key]}
    for v in VERBS
    for key, lbl in _FIELDS_V
]

# State cell
cv_v, set_cv_v               = mo.state(None)
remaining_v, set_remaining_v = mo.state(None)
score_v, set_score_v         = mo.state({'correct': 0, 'total': 0})
history_v, set_history_v     = mo.state([])
future_v, set_future_v       = mo.state([])
restore_entry_v, set_restore_entry_v = mo.state(None)

# Widgets cell
_ = cv_v()
write_input_v, dia_v, check_btn_v, prev_btn_v, next_btn_v = gu.word_drill_widgets(
    restore_entry=restore_entry_v(),
    done=cv_v() is None and remaining_v() is not None and len(remaining_v()) == 0,
    history_len=len(history_v()),
)

# Form cell
gu.word_drill_form(
    cv_v, set_cv_v, remaining_v, set_remaining_v,
    score_v, set_score_v, restore_entry_v, set_restore_entry_v,
    history_v, set_history_v, future_v, set_future_v,
    write_input_v, dia_v, check_btn_v, prev_btn_v, next_btn_v,
    vocab=VERB_ENTRIES,
    title='## Упражнение 1 · ...',
    form_key='form',
)
```

## State variable suffix convention

| suffix | exercise | example |
|--------|----------|---------|
| `_v`   | word_drill verbs | `cv_v`, `score_v`, `restore_entry_v` |
| `_a`   | word_drill adverbs (Pattern A) | `cv_a`, `score_a`, `restore_entry_a` |
| `_c`   | word_quiz choices | `cv_c`, `score_c`, `restore_entry_c`, `answer_radio` |
| `_w`   | word_drill words | `cv_w`, `score_w`, `restore_entry_w` |

Use these suffixes consistently so cell dependencies stay unambiguous when two exercises share a notebook.

## TSV format

All vocabulary TSVs use exactly two columns: `Word` and `Translation`.

```
Word\tTranslation
λέγω\tговорить
ὁ ἀγρός\tполе (ager)
καλός, -ή, -όν\tкрасивый (pulcher)
```

- `Word` — the form as the learner will see/type it (may include article, may be
  `Adj, -ή, -όν` pattern for adjectives)
- `Translation` — Russian gloss; parenthetical Latin is allowed and encouraged
- Multi-word entries are intentional (e.g. `ἐπαίρει ἑαυτόν`) — do not split them
- Use `gu.load_vocab_tsv("verbs.tsv", "nouns.tsv", ..., nb_dir=NB_DIR, remote_base=NB_REMOTE)`
  to load one or more TSVs into `VOCAB_WORDS` for Pattern B exercises

## Adding a new lesson

1. Create `YYYY_MM_DD/` directory.
2. Add TSV files (`verbs.tsv`, `nouns.tsv`, etc.) with `Word\tTranslation` columns.
3. Copy the closest existing `notebook.py` as a starting template.
4. Update: title cell (lesson number/name), `NB_REMOTE`, `mo.md` lecture content,
   exercise `title=`, homework cell.
5. Choose the pattern:
   - **Pattern A** if exercises need backend-inflected forms (`slot_drill` or ADV drill).
   - **Pattern B** if exercises use TSV forms as-is (`word_quiz` + `word_drill`).
6. Upload to molab, copy the `nb_id`, add a row to `lessons.tsv`.
7. Update the molab badge URL in the title cell.
