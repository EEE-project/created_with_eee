## 3. GRAMMAR (Για δες)

### A. Απλός Μέλλοντας (Simple Future) (pp. 126-127)

**Formation:** θα + the same stem-change the aorist uses (present → aorist → simple future all share the stem alternation, only the personal endings differ):

| Present | Aorist | Simple Future |
|---|---|---|
| αγοράζω | αγόρασα | **θα αγοράσω** |
| δουλεύω | δούλεψα | **θα δουλέψω** |
| μιλάω | μίλησα | **θα μιλήσω** |
| πετάω | πέταξα | **θα πετάξω** |
| βάζω | έβαλα | **θα βάλω** |

**Type A** (stem ends in a consonant):
- -νω, -ζω, -θω → **-σω**: πληρώνω → θα πληρώσω, αγοράζω → θα αγοράσω, νιώθω → θα νιώσω
- -ζω, -γω, -χω, -χνω, -κω, -σκω → **-ξω**: κοιτάζω → θα κοιτάξω, ανοίγω → θα ανοίξω, τρέχω → θα τρέξω, φτιάχνω → θα φτιάξω, μπλέκω → θα μπλέξω, διδάσκω → θα διδάξω
- -εύω, -πω, -φω, -βω, -πτω → **-ψω**: δουλεύω → θα δουλέψω, λείπω → θα λείψω, γράφω → θα γράψω, ανάβω → θα ανάψω, βλάπτω → θα βλάψω

**Type B1/B2** (stressed endings):
- **-ήσω**: μιλάω → θα μιλήσω, τηλεφωνώ → θα τηλεφωνήσω, ζω → θα ζήσω
- **-άσω**: γελάω → θα γελάσω, διψάω → θα διψάσω, ξεχνάω → θα ξεχάσω
- **-έσω**: φοράω → θα φορέσω, καλώ → θα καλέσω, μπορώ → θα μπορέσω
- **-ήξω**: πηδάω → θα πηδήξω, τραβάω → θα τραβήξω, φυσάω → θα φυσήξω, βουτάω → θα βουτήξω
- **-άξω**: κοιτάω → θα κοιτάξω, πετάω → θα πετάξω, φυλάω → θα φυλάξω

**Full conjugation** (5 verb types side by side): θα αγοράσω/αγοράσεις/αγοράσει/αγοράσουμε/αγοράσετε/αγοράσουν(ε) · θα γράψω/γράψεις/γράψει/γράψουμε/γράψετε/γράψουν(ε) · θα τραβήξω/τραβήξεις/τραβήξει/τραβήξουμε/τραβήξετε/τραβήξουν(ε) · θα πετάξω/πετάξεις/πετάξει/πετάξουμε/πετάξετε/πετάξουν(ε) · θα πω/πεις/πει/πούμε/πείτε/πουν(πούνε)

**Irregular verbs** (as printed): ανεβαίνω → θα ανέβω/ανεβώ, αρρωσταίνω → θα αρρωστήσω, βάζω → θα βάλω, βγάζω → θα βγάλω, βγαίνω → θα βγω, βλέπω → θα δω, βρίσκω → θα βρω, δίνω → θα δώσω, είμαι → θα είμαι, έχω → θα έχω, θέλω → θα θελήσω, καίω → θα κάψω, κάνω → θα κάνω, καταλαβαίνω → θα καταλάβω, κατεβαίνω → θα κατέβω/κατεβώ, κλαίω → θα κλάψω, λέω → θα πω, μαθαίνω → θα μάθω, μένω → θα μείνω, μεθάω → θα μεθύσω, ξέρω → θα ξέρω, μπαίνω → θα μπω, παθαίνω → θα πάθω, παίρνω → θα πάρω, πεθαίνω → θα πεθάνω, περιμένω → θα περιμένω, πέφτω → θα πέσω, πηγαίνω/πάω → θα πάω, πίνω → θα πιω, πλένω → θα πλύνω, στέλνω → θα στείλω, τρώω → θα φάω, φέρνω → θα φέρω, φεύγω → θα φύγω, γίνομαι → θα γίνω, έρχομαι → θα έρθω, κάθομαι → θα καθίσω/κάτσω

**Weak object-pronoun placement** (p. 127) — the weak pronoun goes between θα and the verb:
- Θα διαβάσουν την εφημερίδα. → **Θα τη διαβάσουν.**
- Θα φέρετε σε εμάς παγωτό; → **Θα μας φέρετε παγωτό;**
- Θα πω σε εσάς κάτι. → **Θα σας πω κάτι.**
- – Θα το ανοίξουν το μαγαζί; – Όχι. **Δε θα το ανοίξουν.**

### B. Υποθετικές προτάσεις — Τύπος Α (Conditional sentences, Type 1) (p. 130)

**Αν + Απλός Μέλλοντας (χωρίς το "θα") → Απλός Μέλλοντας** — i.e. the "if"-clause uses the plain future-tense stem/endings but drops θα; the result-clause is a normal simple future:

- Αν **βρέξει** αύριο, δε **θα πάμε** για περπάτημα στο βουνό.
- Αν **αρχίσεις** γυμναστική, **θα νιώσεις** πολύ καλύτερα.
- Αν **έρθεις**, **θα φάμε** μαζί το μεσημέρι.
- Αν **διαβάσεις** περισσότερο, **θα περάσεις** στις εξετάσεις.
- Αν του **τηλεφωνήσεις** τώρα, **θα τον βρεις**.

### p. 123 — weather expressions (Για δες)

- **Θα κάνει / Θα έχει**: ζέστη, καύσωνα, κρύο, ψύχρα, δροσιά, παγωνιά, καλό/ωραίο καιρό, κακό/άσχημο καιρό, κακοκαιρία, παλιόκαιρο
- **Θα έχει**: ήλιο, λιακάδα, αέρα, άνεμο, συννεφιά, σύννεφα, βροχή, καταιγίδα, χιόνι, χιονόνερο, χαλάζι, ομίχλη, υγρασία

- **Ο καιρός**: θα φτιάξει / θα χαλάσει
- **Η θερμοκρασία**: θα ανέβει / θα πέσει / θα φτάσει τους 18°C (τους 18 βαθμούς Κελσίου) / θα φτάσει τους -5°C (τους μείον 5 βαθμούς Κελσίου / τους 5 βαθμούς κάτω από το μηδέν)
- **Τι καιρό κάνει τώρα εκεί;**: Βρέχει. Ψιλοβρέχει. Ψιχαλίζει. Χιονίζει. Σε λίγο θα το στρώσει. Ρίχνει χιόνι. Ρίχνει χαλάζι. Φυσάει. Έχει αστραπές και βροντές/μπουμπουνητά. Αστράφτει. Βροντάει/Μπουμπουνίζει.
- **Τι καιρό είχατε χτες;**: Έβρεχε συνέχεια. Ο δρόμος μπροστά στο σπίτι έγινε ποτάμι και η αποθήκη μας πλημμύρισε. Όλη τη νύχτα δεν μπορέσαμε να ησυχάσουμε από τις αστραπές και τις βροντές. Ένας κεραυνός έπεσε σε ένα δέντρο δίπλα στο σπίτι μας και το έκαψε.
