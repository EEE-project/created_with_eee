# p.191 — Ενότητα 12 «Ένα ατύχημα στους δρόμους»

## Στα επείγοντα περιστατικά

**B17** — Dialogue at the emergency room:

| | |
|---|---|
| **Γιατρός:** | Λοιπόν, η ακτινογραφία δε δείχνει κάταγμα. Πώς αισθάνεσαι τώρα; |
| **Φοίβος:** | Ζαλίζομαι λίγο... |
| **Γιατρός:** | Αυτό είναι μάλλον λογικό... Ίσως έπαθες μια μικρή διάσεση. Το πόδι σου πονάει ακόμα όπως πριν; |
| **Φοίβος:** | Ε, κάπως λιγότερο, νομίζω. |
| **Γιατρός:** | Λοιπόν... Θα το δέσουμε εδώ... Ωραία... Μπορείς να περπατήσεις; |
| **Φοίβος:** | Εντάξει. Πιο καλά. |
| **Γιατρός:** | Ήσουν πολύ τυχερός. |
| **Φοίβος:** | Μπορώ να πάω στο σπίτι μου, δηλαδή; |
| **Γιατρός:** | Ναι. Αλλά αυτό που χρειάζεσαι τώρα είναι ξεκούραση. Εργάζεσαι; Θέλεις να σου γράψω αναρρωτική άδεια; |
| **Φοίβος:** | Όχι, δεν εργάζομαι. |
| **Γιατρός:** | Εν πάση περιπτώσει, καλό είναι να μείνεις στο κρεβάτι για λίγες μέρες. Δεν πρέπει να κουράζεις το πόδι σου. Όταν πονάς πολύ, μπορείς να βάζεις λίγο πάγο και να παίρνεις αυτά τα παυσίπονα. Επίσης, για δύο μέρες πρέπει να τρως ελαφρά φαγητά. Και αν αύριο συνεχίζεις να νιώθεις ζαλάδα, καλό είναι να έρθεις για εξετάσεις πάλι. |

## Πώς το λένε;

| | |
|---|---|
| **Πώς αισθάνεσαι;** | How are you feeling? |
| **Αυτό είναι μάλλον λογικό.** | That's quite understandable / logical. |
| **Κάπως λιγότερο, νομίζω.** | Somewhat less, I think. |
| **Εν πάση περιπτώσει...** | In any case... / At any rate... |

### Εκφράσεις

| | |
|---|---|
| βγάζω ακτινογραφία | to get an X-ray |
| έχω κάταγμα | to have a fracture |
| ζαλίζομαι = νιώθω ζαλάδα | to feel dizzy |
| παίρνω παυσίπονα | to take painkillers |
| βάζω πάγο | to apply ice |
