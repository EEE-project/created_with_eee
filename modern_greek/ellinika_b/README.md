# Ελληνικά Β — Modern Greek

Interactive notebooks chaptered to match the "Ελληνικά Β" (B1) textbook —
grammar, vocabulary, and phrase drills per chapter, built with
[EEE](https://codeberg.org/EEE-project/eee-project) and [Marimo](https://marimo.io).

**Live:**
- [GitHub Pages](https://eee-project.github.io/created_with_eee/modern_greek/ellinika_b/)
- [GitLab Pages](https://eee-project.gitlab.io/created_with_eee/modern_greek/ellinika_b/)
- [Codeberg Pages](https://eee-project.codeberg.page/created_with_eee/modern_greek/ellinika_b/)

10 chapters built (`chapter_01`–`chapter_04`, `chapter_06`–`chapter_09`,
`chapter_11`, `chapter_12` — 05 and 10 are pure repetition in the textbook
itself, deliberately skipped).

See [`AGENTS.md`](AGENTS.md) for directory layout and content-verification
notes per chapter.
