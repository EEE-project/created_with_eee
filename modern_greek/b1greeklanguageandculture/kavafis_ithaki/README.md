# Kavafis — Ithaki

Trilingual (ru/el/en) notebooks on C. P. Cavafy's poem *Ithaka* (Ιθάκη) — the
Greek text alongside multiple literary translations, slide-based biography
and discussion material, and vocabulary drills. Part of the B1: Ελληνική
Γλώσσα και Πολιτισμός course, built with
[EEE](https://codeberg.org/EEE-project/eee-project) and [Marimo](https://marimo.io).

**Live:**
- [GitHub Pages](https://eee-project.github.io/created_with_eee/modern_greek/b1greeklanguageandculture/kavafis_ithaki/)
- [GitLab Pages](https://eee-project.gitlab.io/created_with_eee/modern_greek/b1greeklanguageandculture/kavafis_ithaki/)
- [Codeberg Pages](https://eee-project.codeberg.page/created_with_eee/modern_greek/b1greeklanguageandculture/kavafis_ithaki/)

2 lessons, numbered (not dated) to match the source material's own numbering.

Uses a different notebook architecture than Kapodistrias/Zorba — see
[`../AGENTS.md`](../AGENTS.md) ("Kavafis Ithaki: a second notebook
architecture") before making structural changes.
