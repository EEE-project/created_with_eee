# Kapodistrias — Greek Language and Culture

Trilingual (ru/el/en) notebooks on Ioannis Kapodistrias, the first governor
of modern Greece — biography and history slides paired with noun/verb/
adjective vocabulary drills. Part of the B1: Ελληνική Γλώσσα και Πολιτισμός
course, built with [EEE](https://codeberg.org/EEE-project/eee-project) and
[Marimo](https://marimo.io).

- [GitLab Pages](https://eee-project.gitlab.io/created_with_eee/modern_greek/b1greeklanguageandculture/kapodistrias/)
- [Codeberg Pages](https://eee-project.codeberg.page/created_with_eee/modern_greek/b1greeklanguageandculture/kapodistrias/)
