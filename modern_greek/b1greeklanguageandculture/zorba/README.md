# Zorba — Greek Language and Culture

Trilingual (ru/el/en) notebooks on Alexis Zorbas (Αλέξης Ζορμπάς) — Kazantzakis'
*Zorba the Greek* — biography and discussion slides paired with noun/verb/
adjective vocabulary drills. Part of the B1: Ελληνική Γλώσσα και Πολιτισμός
course, built with [EEE](https://codeberg.org/EEE-project/eee-project) and
[Marimo](https://marimo.io).

**Live:**

- [GitLab Pages](https://eee-project.gitlab.io/created_with_eee/modern_greek/b1greeklanguageandculture/zorba/)
- [Codeberg Pages](https://eee-project.codeberg.page/created_with_eee/modern_greek/b1greeklanguageandculture/zorba/)

3 lessons (one per lecture date).
