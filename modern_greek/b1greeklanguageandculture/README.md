# B1: Ελληνική Γλώσσα και Πολιτισμός

Greek language and culture lessons built around historical and literary
figures — trilingual (ru/el/en) slides paired with vocabulary drills, drawn
from the same B1-level lecture series.

**Live:**
- [GitHub Pages](https://eee-project.github.io/created_with_eee/modern_greek/b1greeklanguageandculture/)
- [GitLab Pages](https://eee-project.gitlab.io/created_with_eee/modern_greek/b1greeklanguageandculture/)
- [Codeberg Pages](https://eee-project.codeberg.page/created_with_eee/modern_greek/b1greeklanguageandculture/)

## Courses

- **[Kapodistrias](kapodistrias/)** — Ioannis Kapodistrias, first governor of
  modern Greece.
- **[Zorba](zorba/)** — Alexis Zorbas, Kazantzakis' *Zorba the Greek*.
- **[Kavafis' Ithaki](kavafis_ithaki/)** — C. P. Cavafy's poem *Ithaka*.

See [`AGENTS.md`](AGENTS.md) for shared directory layout and notebook
structure across all three.
