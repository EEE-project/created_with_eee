# Φωνή-Γραφή

------------------------------------
| με, σε | | φωνήεν | | μ', σ'| |
| το | **+** | ο, α | **->** | τ'| με άκουγε = μ' άκουγε |
| τα | | α | | τ'| σε έβλεπε = σ' έβλεπε |
------------------------------------
------------------------------------

|                                      | μου '- | μου έλεγε = μου 'λεγε |
|                                      | σου '- | σου έστελνε = σου 'στέλνε |
| μου, σου, του, το, τα **+** [e-, i-] | του '- | του έφερενε = του 'φερνε |
|                                      | το '- | το ήξερε = το 'ξερε |
|                                      | τα '- | τα έδινε = τα ´δινε |
------------------------------------
